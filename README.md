# UAN PRO — instaladores oficiais

Sistema profissional de gestão de Unidades de Alimentação e Nutrição (UAN) para Windows: cardápio de 6 semanas validado no calendário, fichas técnicas, Ordem de Produção e Ordem de Estoque, compras, estoque com balanço e CMV real, DRE fechada por mês, qualidade, pasta da Vigilância e o Painel da Cozinha.

**Conheça e faça a Degustação de 14 dias:** [uannodiaadia.com/uanpro](https://uannodiaadia.com/uanpro)

## Baixar

A versão mais recente está sempre em **[Releases → Latest](../../releases/latest)**. Baixe o arquivo `UAN-PRO-Setup-<versão>.exe`.

- **Windows 10 ou 11**, 64 bits.
- O instalador é **assinado digitalmente** (Certum). Na instalação, o Windows mostra como editor *Osmar Carneiro Pinto Almeida*.
- Quem já usa não precisa baixar de novo: o programa avisa sozinho quando há versão nova. Para adiantar: **Configurações → Buscar atualizações**.

## O que há de novo

As notas de cada versão ficam na página da própria release, em [Releases](../../releases).

## Importante

Este repositório é a fonte da **atualização automática** do UAN PRO: os arquivos `latest.yml` e `.blockmap` de cada release são lidos pelo programa instalado nos computadores dos clientes. Não renomeie o repositório nem apague esses arquivos das releases.

O código-fonte do UAN PRO não é público. Este repositório contém apenas os instaladores.
